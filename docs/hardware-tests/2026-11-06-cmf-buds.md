## Observed

- The model id reply `68 B1` identifies the buds; battery was left 90, right 100, case 60.
- Setting `01 07 00` gave the ack `700F` and the push `E003` with `07`, and the buds switched to transparency. The `401E` read afterwards showed `07`.
- Setting `01 01 00` gave noise cancelling; the read and the push echoed `01`. The values `02` and `03` were echoed the same way.
- Setting `01 04 00` was ignored: no change in the mode.
- `F01D` with `01 00` (Rock) and `06 00` (Custom) were acked with `701D`, and `C050` then read back the same preset.
- `F010` did not move the value read by `C050`; `C01F` and `F010` are a different register on this model.
- Acks carry `FF FF` in the CRC position, so the CRC of received frames is not checked.
